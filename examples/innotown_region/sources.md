# 처치 시점 근거 — 강소연구개발특구 지정 연도

## 1차: 연구개발특구진흥재단 홈페이지 「강소특구란?」 (조회 2026-10-20, 내장 브라우저로 본문 확보)
URL: https://www.innopolis.or.kr/board?menuId=MENU01123
원문 발췌(그대로):
```
‘19년 지정  경기 안산 / 경남 김해 / 경남 진주 / 경남 창원 / 경북 포항 / 충북 청주
‘20년 지정  경북 구미 / 전북 군산 / 전남 나주 / 울산 울주 / 서울 홍릉 / 충남 천안아산
‘22년 지정  인천 서구
```
페이지 제목은 "13개 강소특구", 본문 한 곳에는 "전국 14개 강소연구개발특구"라고 적혀 있어 개수가 어긋난다.

## 2차(보도): 강원 춘천
- 과기정통부가 2022.5.2. 인천 서구·강원 춘천을 신규 지정했다는 보도(smarttoday 2022-05-02, 강원대 보도자료 2022-05-03). 그러나 특구재단 현행 목록(위)에는 춘천이 없다 — 지정 해제 또는 목록 누락 여부를 원문으로 확인하지 못함.
- 처리: 강원은 `exclude_units`(처치 여부가 원문으로 확정되지 않음). 미처치로 두면 오분류 위험.
